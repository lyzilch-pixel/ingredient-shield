## 4. 交叉接触风险（cross_contact_risks）

依据 GB 7718-2011 对"可能含有……"式交叉接触提示的精神，注册表内置三类常见场景：

- 油炸设备共用 → 鱼/甲壳类交叉污染（薯条、炸鸡等）
- 面包房设备残留 → 坚果、芝麻碎屑（面包、糕点）
- 酱料管线交替 → 蛋/乳/大豆配方交替（酱、沙拉）
