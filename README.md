# 🛡️ 成分避雷 (IngredientShield)

> **跨品类消费品安全决策引擎 · 食品 / 日化个护 / 药品**
> 把"看不见的成分风险"变成"可查询、可预警、可决策"的结构化信息

---

## 一句话价值

> **不是帮你买，是帮你"安全地买"。**
> 一份跨品类的个人安全画像，覆盖食品过敏原、日化致敏原/风险物质、药品禁忌——一次配置，食品/日化/药品同时避雷。

---

## 痛点场景

| 用户 | 痛点 |
|------|------|
| 过敏体质者 | 不知食品/药品是否含致敏原，选购如"赌博" |
| 宝妈 / 育儿家庭 | 儿童食品成分、日化致敏原、用药禁忌不透明 |
| 孕期 / 哺乳期 | 哪些药品、成分绝对不能碰，缺乏一站式提示 |
| 敏感肌 / 成分党 | 日化护肤品里的 MIT、香精、甲醛释放体看不懂 |
| 普通消费者 | 跨品类召回 / 预警滞后知晓 |

---

## 覆盖品类（V1）

- **食品** — 14 类过敏原（含交叉污染"可能含"）、营养风险（高钠/高糖/反式脂肪）、食品召回
- **日化个护** — 致敏原（MIT/香精/SLS 等）、风险物质（甲醛释放体/煤焦油等）、监管召回
- **药品** — 成分过敏（青霉素/阿司匹林/磺胺类）、健康禁忌（孕期/哺乳/未成年/肝肾等）、说明书预警

---

## 功能

- 🔍 **成分风险标注**：食品过敏原、日化致敏原/风险物质、药品成分过敏，统一"成分→危害"映射
- 🚫 **健康禁忌校验**：孕期、哺乳期、未成年、肝肾、服药禁酒/勿驾驶等状态一键规避禁忌药品
- 🥗 **营养风险标注**：高钠 / 高糖 / 含反式脂肪 / 高热量（食品品类）
- 🧬 **溯源 / 资质**：原料产地、资质、认证摘要（开源知识库）
- 🚨 **跨品类预警**：近 24h 召回 / 事件推送（食品 / 日化 / 药品）
- 📋 **安全清单**：一键生成可分享的"我的安全消费清单"卡片（跨品类汇总）

## 架构

```
用户 → WorkBuddy Skill → 规则编排层（rules）
                ├→ 统一危害注册表（component_db：食品/日化/药品危害）
                ├→ 品类分析器（nutrition / product_safety / drug_safety）
                ├→ 溯源/资质（provenance）
                ├→ 跨品类召回预警（safety_alert）
                └→ 可插拔数据源（data_source：本地演示库，真实源可替换）
                ↓
          结果聚合 → 前端展示 / 分享卡片
```

**不绑定任何单一品牌或单一 MCP**：数据源通过统一接口 `list_products()` 提供产品清单，本地演示用 `products.json`，真实接入时可替换为公开食品成分库、化妆品成分数据库、药品说明书库与监管召回源。

## 数据来源与免责

- 过敏原分类依据 Codex / EU 14 类 + 中国 GB 7718 强制 8 类整理
- 营养阈值依据《中国居民膳食指南（2022）》单份占比
- 日化/药品危害依据公开成分安全资料与药品说明书共识整理
- **本项目所有数据均为开源演示知识库，非任何品牌或监管官方数据，仅供参考，不构成医疗、用药或法律建议**
- 真实接入后，请以品牌官方公示与监管部门（市场监管总局 / 药监局 / 疾控中心）权威发布为准
